# Projeto: CLT Calculador

Ele tem como objetivo permitir que trabalhadores e empregadores realizem cálculos trabalhistas de forma didática e intuitiva.


## Tecnologias Utilizadas

- **Vite**: Ferramenta de build rápida para desenvolvimento de frontends modernos.
- **React**: Biblioteca para criação de interfaces de usuário.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática.
- **CSS Framework**: A definir, com foco em minimalismo e responsividade.

## Requisitos

- Node.js (versão 18 ou superior)
- npm ou yarn

## Instalação

1. Clone este repositório:
   ```bash
   git clone https://github.com/mattsousadev/clt-calculador.git
   ```

2. Acesse o diretório do projeto:
   ```bash
   cd clt-calculador
   ```

3. Instale as dependências:
   ```bash
   npm install
   # ou
   yarn
   ```

## Uso

1. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   # ou
   yarn dev
   ```

2. Abra o navegador e acesse:
   ```
   http://localhost:5173
   ```

## Scripts Disponíveis

- `npm run dev` / `yarn dev`: Inicia o servidor de desenvolvimento.
- `npm run build` / `yarn build`: Gera uma versão otimizada para produção.
- `npm run preview` / `yarn preview`: Visualiza a versão gerada para produção localmente.
